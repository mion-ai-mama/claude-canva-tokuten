# 要件定義書：Claude×Canva連携 完全ガイド

作成日: 2026-09-15

## アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）の最小形＝静的1ページサイト
- 操作者: ブラウザのエンドユーザー（Instagramリールから訪れる読者）
- AI本体(プロンプトY): なし（ページ自体はAIを呼ばない。AIに渡す「文章」を配布するページ）

- フロントUI: あり（HTML/CSS/Vanilla JS のみ）
- 動的変数: なし
- 種別: Web型
- 配布: 公開Webページ（GitHub Pages）

> Phase 7（エージェント構築）・Phase 8（MCP実装）は対象外。

## 1. プロジェクト概要

Instagramリールの特典として配布する、スマートフォン最優先の1ページ完結ガイド。
ClaudeとCanvaを連携し、Instagram投稿やバナーのデザイン案を作ってCanvaで仕上げられるようになることを目的とする。

連携方法の紹介にとどめず、実際の検証で分かった失敗例・修正方法・用途別のコピペ用プロンプトまで掲載する。

### 成功指標

| 種別 | 指標 |
|---|---|
| 定量 | 横スクロール0件（320 / 375 / 1280px）／JSエラー0件／プロンプト11か所すべてがワンタップでコピー可能 |
| 定量 | 本文16px以上・行間1.8・タップ領域48px以上 |
| 定性 | AI初心者が上から順に読み進めるだけで連携〜生成〜修正まで到達できる |
| 定性 | 誇張表現・未確認の断定を含まない（「必ず時短」等を使わない） |
| 定性 | 情報量は多いが詰め込んで見えない（カード・開閉式・アコーディオンで段階表示） |

### 想定読者

AI初心者／40〜50代女性／Canva使用経験はあるがデザインに自信がない／
専門用語が苦手／スマートフォンでの閲覧・操作が中心。

## 2. システム全体像

静的ファイルのみ。サーバー処理・認証・DB・外部APIは一切なし。
JavaScriptは次の3機能のみを担当する。

| 機能 | 内容 |
|---|---|
| 画像プレースホルダー | 画像が未配置のとき「ここに◯◯の画像を入れてください」の枠に差し替える |
| コピー | プロンプトをクリップボードへコピーし「コピーしました！」を表示 |
| 先頭へ戻る | 600px以上スクロールしたときだけボタンを表示 |

JavaScriptが無効でも、文章・画像・目次リンクはそのまま読める。

### プロンプトの汎用化（穴埋め式テンプレート）

4つのプロンプトはすべて、読者が自分の内容に差し替えて使えるテンプレートとして書く。

- 書き換える場所は `〈…〉` で囲み、かっこ内に「何を入れるか」と「例」を併記する
- 各カードの冒頭に「書き換えるのはここだけ」のガイドを置く
- プロンプトの【厳守事項】に
  「〈　〉が残っている場合は、デザインを作らずに、そこに何を入れるか質問してください」を入れ、
  書き換え忘れのまま送られてもClaudeが聞き返すようにする
- `〈…〉` は `script.js` が実行時に `<span class="fill">` で囲んで強調する。
  文字そのものは変えないため、コピーされる内容は表示と完全に一致する
- 5-2 はサイズを横長1200×628 / 正方形1080×1080 / 縦長1080×1350 から選べる形にし、
  レイアウト指示もサイズに応じて選択する書き方にする

### 完成例の表示

5-1・5-2では、Canvaで仕上げた完成例を1枚だけ載せる（「生成直後」は載せない）。
画像はタップで原寸表示できるようにする（スマホで細部が見えないため）。

## 4. データ設計概要

永続データなし。チェックリストの状態は保存しない（再読み込みでリセット）。

## 5. セキュリティ要件

- 外部リンクはすべて `target="_blank"` + `rel="noopener noreferrer"`
- 入力フォーム・個人情報の収集なし
- 外部スクリプト・トラッカーの読み込みなし
- GitHub Pages は HTTPS 配信

## 6. 技術スタック

HTML5 / CSS3（カスタムプロパティ・Grid・`aspect-ratio`）/ Vanilla JavaScript（ES5互換の書き方）。
ビルドツール・パッケージ依存なし。`index.html` を直接開いても動作する。
